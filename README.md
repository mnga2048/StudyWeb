# StudyWeb · 专业课学习平台

> 面向电子、自动化、电气、通信专业学生与备考同学的**专业课一站式学习网站**。
> 应试（学习笔试）与工程（实战应用）双线并重，把分散的知识系统化、可视化、可交互地组织。
> 特别增设**机器人控制方向**（机器人学/电机拖动/嵌入式/传感器/现代控制）、**Linux 开发板实战**、**3D 打印**与**人工智能与边缘部署**课程，并以"Linux+STM32 两轴写字机"贯穿项目串起控制、结构与智能三条主线。

[![线上访问](https://img.shields.io/badge/线上访问-Vercel-2563eb)](https://study-web-cckiller.vercel.app) [![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

## ✨ 核心特性

- **📚 21 大板块**：覆盖数学→电子→控制→嵌入式→机器人→制造→计算机→人工智能全栈知识
- **🧮 公式可视化**：KaTeX 渲染全部数学/控制公式，配套 37 个计算工具（电路/控制/信号/嵌入式/制造/人工智能等 11 大分类）
- **🎮 交互图表**：伯德图、根轨迹、奈奎斯特判稳、PID 仿真、卷积动画、FFT 谐波合成、注意力热力图、Agent 循环等 22 种可交互图表
- **✏️ 自测练习**：1221 道自测题，覆盖全部 229 个知识点，含解析与错题记录
- **✍️ 笔记与收藏**：知识点笔记（Markdown）+ 收藏分类（待复习/已掌握/易错点）
- **📊 学习进度**：知识图谱、掌握度热力图、学习推荐、薄弱环节分析
- **🧰 贯穿项目**：Linux+STM32 两轴写字机——linux（控制）+ print（结构）+ ai（智能）+ motor/mct（理论与选型）在同一台机器上闭环
- **🌙 深色模式** + 响应式布局，移动端友好
- **🔍 全文搜索**：支持标题、简介、标签检索，关键词高亮

## 🚀 本地预览

纯前端静态站点，无需构建。任选一种方式：

```bash
# 方式一：Python 内置服务器
python -m http.server 8000
# 浏览器访问 http://localhost:8000

# 方式二：直接双击 index.html（部分浏览器对本地文件有限制，推荐用服务器）

# 方式三：npx serve
npx serve .
```

## 🛠 技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 样式 | Tailwind CSS (CDN) | 原子化布局 |
| 主题 | 原生 CSS 变量 | 学术蓝 + 深色模式 |
| 公式 | KaTeX + auto-render | 数学/控制公式渲染 |
| 图表 | ECharts 5 | 波形图、知识图谱、进度图 |
| 路由 | 原生 JS SPA | 单页应用，无框架 |
| 存储 | localStorage | 进度/收藏/答题/主题 |
| 构建 | 零构建 | 双击即用 |
